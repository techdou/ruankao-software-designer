## 本章考情

每年 5~7 分。**PV 操作（前驱图/生产者消费者）和页式地址变换是两大必考计算题**；死锁、页面置换、位示图轮换着出。PV 前驱图题需要会读图，讲义里给了通用模板。

## 5.1 进程与状态转换

### 精讲

进程 = 程序 + 数据 + **PCB**（进程控制块，唯一标识）。**三态模型**：

- **运行** →（时间片到/被高优先级抢占）→ **就绪**
- **运行** →（等待 I/O / 资源）→ **等待（阻塞）**
- **就绪** →（被调度选中）→ **运行**
- **等待** →（事件完成）→ **就绪**（**不能直接去运行**）

> 【例】P1 运行中释放了打印机（P3 正等该打印机），P1~P4 状态？→ P1 继续**运行**（主动释放资源不阻塞）、P3 等待→**就绪**、其余不变。注意：主动释放资源的进程不会因此变就绪。

**线程**：共享所属进程的资源（代码、数据、打开文件），独享栈与寄存器上下文；同进程线程切换开销小。

### 易错警示

- 等待态不能直接转运行态，必须先进就绪队列——状态转换图的方向题年年设陷阱。

## 5.2 PV 操作（必考）

### 精讲

**信号量 S**：S > 0 表示可用资源数；S < 0 的绝对值 = 等待的进程数。
- P(S)：申请资源，S−1；若 S<0 则阻塞。
- V(S)：释放资源，S+1；若有等待者则唤醒。

**取值范围题**：n 个进程共用 5 个资源 R，信号量 S 取值范围 **[−(n−5), 5]**（最多 5 个同时进，最多 n−5 个等待）。

**前驱图模板**（每年考）：每条边一个信号量 $S_i$。规则：

- 进程做完某件事 → **V**（通知后继）
- 进程开始前 → 对所有入边 **P**（等待前驱）

> 【例】P1 →(S1)→ P2 →(S2)→ P3，P1 →(S3)→ P3：
> P1：…; V(S1); V(S3);
> P2：P(S1); …; V(S2);
> P3：P(S2); P(S3); …（P 操作顺序可互换）

**生产者-消费者**：互斥信号量 mutex（初值 1）、同步信号量 empty（初值缓冲区大小）、full（初值 0）。**先 P 同步信号量，再 P 互斥信号量**，顺序颠倒会死锁。

### 易错警示

- 互斥信号量初值恒为 **1**，与竞争进程数无关。
- 前驱图题数边定信号量个数；答案选项里先按"完成即 V、开始前 P"过滤。

## 5.3 死锁

### 精讲

**四个必要条件**（缺一不可，破坏任一即可预防）：

1. **互斥**
2. **请求保持**（占有并等待）
3. **不可剥夺**
4. **环路等待**

**避免**：银行家算法——"试探分配后能找到安全序列则分配"。

**资源分配图**：能化简则无死锁；每类资源只有一个时，**有环 ⇔ 死锁**。

> 【例】n 个进程、每进程需 k 个资源，不发生死锁至少需要 $n(k-1)+1$ 个资源。

### 易错警示

- "破坏环路等待" = 资源有序分配法；"一次性申请全部资源"破坏的是请求保持。

## 5.4 存储管理（必考计算）

### 精讲

**页式**：逻辑地址 = 页号 + 页内偏移。**页号 = 逻辑地址 ÷ 页大小（取整），偏移 = 逻辑地址 mod 页大小**。物理地址 = 物理块号 × 页大小 + 偏移。页号查**页表**得物理块号。优点：内存利用率高；缺点：**无内外存保护、产生内部碎片**（最后一页不满）。

> 【例】页大小 4K=2¹²，逻辑地址 3C20H：低 12 位 C20H 是页内偏移，高位 3 是页号，查页表得物理块，物理地址 = 块号×1000H + C20H。

**段式**：按逻辑功能分段（主程序段、子程序段），段表存段长和基址——**便于共享保护**，产生**外部碎片**。段页式：先分段再分页，兼有两者优点。

地址结构题（如"段号 9 位、页号 11 位、页内 13 位"）：**最多段数 = 2⁹ = 512；每段最大页数 = 2¹¹ = 2048；页大小 = 2¹³ = 8K**。注意"每段大小均为"错——段内页数可以不同，"最大允许"对。

**页面置换**（缺页计算）：

| 算法 | 规则 | 特点 |
|---|---|---|
| FIFO | 淘汰最先进入的 | 有 Belady 异常（块多缺页可能反增） |
| **LRU** | 淘汰**最近最久未使用** | 性能好，需记录访问时间 |
| OPT | 淘汰以后最久不用的 | 理论最优，无法实现 |

**虚拟存储器**：局部性原理 + 请求分页/分段；页表带状态位（在内存？）、访问位、修改位（淘汰时脏页要写回）。

### 易错警示

- 十六进制地址拆分先算页内偏移位数（页大小 4K → 低 12 位），剩下的高位才是页号。
- LRU 看的是"最近是否被用过"，FIFO 看的是"来的早晚"。

## 5.5 文件管理

### 精讲

**索引节点**：iaddr[0..9] 直接地址块、iaddr[10] 一级间接、iaddr[11] 二级间接……每地址项指向 1 个块，块大小 1KB、每地址 4B → 每个间接块存 256 个地址。

> 【例】直接 + 一级间接 + 二级间接可寻址的文件最大长度 = (10 + 256 + 256²) × 1KB。

**位示图**：每盘块对应 1 位（0 空闲 1 占用）。字长 32 位时，字数 = 块数 ÷ 32。

> 【例】2048GB 磁盘、8MB 物理块、32 位字长：块数 = 2²¹MB/2³MB = 2¹⁸，字数 = 2¹⁸/2⁵ = **8192 字**。

**空闲空间管理**：位示图、空闲块链、成组链接法（Unix）。

### 易错警示

- 位示图先统一单位（GB→MB→块数），再除以字长——单位换算错最常见。

## 5.6 设备与作业调度

### 精讲

- **Spooling（假脱机）**：用磁盘缓冲把独占设备改造成共享设备（打印机）。
- **磁盘调度**：FCFS、SSTF（最短寻道优先，易"饥饿"）、SCAN（电梯算法，单向扫）。
- **作业调度算法**：FCFS、SJF（短作业优先，平均周转时间最短但可能"饥饿"）、响应比高者优先 HRN =（等待+服务）/服务。

### 易错警示

- SJF 平均等待最短但对长作业不公平；HRN 是 FCFS 与 SJF 的折中。

## 考前速记

| 考点 | 一句话 |
|---|---|
| 状态转换 | 等待不能直达运行 |
| 信号量互斥 | 初值恒为 1 |
| 信号量范围 | [−(n−可用数), 可用数] |
| 前驱图 | 做完 V，开做 P，几条边几个信号量 |
| 死锁四条件 | 互斥、请求保持、不可剥夺、环路等待 |
| 不死锁资源数 | n(k−1)+1 |
| 页式地址 | 低位偏移、高位页号查页表 |
| LRU / FIFO | 最近最久未用 / 先来先走（Belady） |
| 位示图字数 | 块数 ÷ 字长 |
| SJF / HRN | 平均周转最短 / 折中防饥饿 |
