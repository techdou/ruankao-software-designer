## 本章考情

每年 4~6 分。**"该问题适合哪种策略"是万能题型**——给你算法特征（最优子结构、贪心选择、解空间搜索方式），让你选分治/贪心/DP/回溯/分支限界。渐进复杂度比较和经典算法（Dijkstra、背包、LCS）配对出题。

## 9.1 渐进分析

### 精讲

$O(f)$：渐进上界。常见复杂度**从低到高**：

$$O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)$$

比较技巧：取 n=1000 代入。$n^{2/3} < \log n$？取 n 充分大时 $n^{0.67} \gg \log n$——**多项式 > 对数**永远成立。

> 【例】$O(\lg n), O(1000n), O(n^{2/3}), O(2^n)$ 从低到高：$\lg n < n^{2/3} < 1000n < 2^n$（常数 1000 不影响阶）。

**主定理速记**：$T(n) = 2T(n/2) + O(n) = O(n\log n)$（归并、快排平均）。

### 易错警示

- 阶的比较只看增长率，常数因子（1000n）与低阶项忽略。
- $O(n\log n)$ 与 $O(n^{1.1})$：取 n 极大时 $n^{1.1}$ 更大——$\log n$ 慢于任何正次幂多项式。

## 9.2 分治法

### 精讲

**三步**：分解（规模减半）→ 求解（递归）→ 合并。特征：子问题**独立**、与原问题同型。

| 算法 | 复杂度 | 合并代价 |
|---|---|---|
| 二分查找 | $O(\log n)$ | O(1)，只算不算 |
| 归并排序 | $O(n\log n)$ | O(n) |
| 快速排序 | 平均 $O(n\log n)$ | 划分 O(n) |
| 最大子段和 | $O(n\log n)$ | 跨中点段 O(n) |

**最大子段和**（$[-2, 11, -4, 13, -5, -2]$ → $11-4+13=20$）：分治 = max(左半、右半、跨中点)，$T(n)=2T(n/2)+O(n)$。

### 易错警示

- 二分查找是"减治"（只递归一边）也归入分治思想考查，答**分治**。
- 折半查找、归并、快排、最大子段和都答分治。

## 9.3 贪心法

### 精讲

每步选**当前最优**（局部最优），不回退；要求**贪心选择性质**（局部最优能导致全局最优）。

| 经典问题 | 贪心策略 |
|---|---|
| 部分背包 | 单位价值最高的先装 |
| 活动选择 | 按结束时间最早 |
| Dijkstra 最短路 | 每次选当前距离最小点 |
| Prim / Kruskal | 最小生成树 |
| Huffman | 每次合并权值最小的两棵 |

**部分背包可贪心**（物品可分割）；**0-1 背包不可贪心**（要动态规划）——这是经典对比考题。

### 易错警示

- Dijkstra 策略选**贪心**（不是 DP）；它不能处理负权边。
- TSP、0-1 背包用贪心得不到最优解。

## 9.4 动态规划（必考识别）

### 精讲

两大特征：**最优子结构**（最优解含子问题最优解）+ **重叠子问题**（递归会重复算同一子问题）→ 自底向上填表，避免重复计算。

| 问题 | 状态转移要点 |
|---|---|
| 0-1 背包 | $f(i,w)=\max(f(i-1,w),\ f(i-1,w-w_i)+v_i)$ |
| LCS 最长公共子序列 | 相等则左上+1，否则 max(上, 左) |
| 矩阵连乘 | 加括号位置枚举，$O(n^3)$ |
| 最大子段和 DP 解 | $b_i=\max(b_{i-1}+a_i,\ a_i)$，$O(n)$ |

> 【例】"问题具有最优子结构和重叠子问题性质，适合（ ）"→ **动态规划**。

### 易错警示

- 0-1 背包不能贪心也不能用普通搜索（指数级）——答 DP。
- DP 与分治的区别：DP 的子问题**重叠**（要记表），分治子问题独立。

## 9.5 回溯与分支限界

### 精讲

都是**在解空间树上搜索**：

| | 回溯法 | 分支限界法 |
|---|---|---|
| 搜索方式 | **深度优先** | **广度优先 / 最小优先** |
| 目标 | 找出**所有**满足条件的解 | 尽快找一个**最优解** |
| 典型 | N 皇后、0-1 背包（求所有可行解）、迷宫 | 旅行商、任务分配 |

> 【例】"以广度优先方式搜索解空间"→ **分支限界法**；"深度优先 + 剪枝"→ 回溯法。

**算法策略识别总口诀**：

- 减半递归 → 分治；局部最优不回头 → 贪心
- 最优子结构 + 重叠子问题 → 动态规划
- 深搜解空间（所有解）→ 回溯；广搜解空间（最优解）→ 分支限界

## 9.6 常考结论速查

- Dijkstra：贪心、$O(n^2)$、忌负权。
- Floyd：动态规划思想、$O(n^3)$、可负权（无负环）。
- 判断"稳定/不稳定、辅助空间"回 ch04 排序表。
- 渐进比较：多项式永远压过对数，指数永远压过多项式。
