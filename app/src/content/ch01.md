## 本章考情

每年上午卷约 5~7 分。出题方式三成记忆（寄存器功能、存储器分类）、五成计算（浮点数、Cache、可靠性、CPI）、两成理解（校验码、寻址）。**补码与可靠性计算几乎年年考**，是拿分基本盘。

## 1.1 CPU 的组成与寄存器

### 精讲

CPU = **运算器（ALU）+ 控制器（CU）+ 寄存器组 + CPU 内部总线**。注意：系统总线在 CPU 之外。

| 部件 | 里面的关键寄存器 |
|---|---|
| 运算器 | ALU、累加器（AC）、数据缓冲寄存器（DR）、状态条件寄存器（PSW） |
| 控制器 | 程序计数器（PC）、指令寄存器（IR）、指令译码器、时序部件、**主存地址寄存器（MAR）、主存数据寄存器（MDR）** |

- **PC（程序计数器）**：存放下一条**待取指令的主存地址**，具有自动加 1 功能——考频最高。
- **IR（指令寄存器）**：存放**当前正在执行的指令本身**。
- **MAR/MDR**：访问主存时的地址/数据中转。
- **PSW**：存溢出、进位、零、负等标志位。

### 例题演算

> 【例】CPU 中，跟踪下一条指令地址的寄存器是（ ）。
> A. 程序计数器  B. 指令寄存器  C. MAR  D. PSW

**答 A**。PC 存"下一条指令的地址"，IR 存"当前指令的内容"，MAR 存"访问主存的地址"。三者的区分是高频考法。

### 易错警示

- 题目问"指令的地址"选 PC，问"指令本身"选 IR——一字之差，答案不同。
- "CPU 的组成不包括系统总线"这类反选题常出现。

## 1.2 原码、反码、补码、移码

### 精讲

设机器字长 8 位，数值 $x$：

| 编码 | 正数 | 负数 | 特点 |
|---|---|---|---|
| 原码 | 符号位 0 + 绝对值 | 符号位 1 + 绝对值 | 有 ±0，表示范围 $-127 \sim +127$ |
| 反码 | 同原码 | 符号位 1，数值位**逐位取反** | 有 ±0 |
| 补码 | 同原码 | 反码 + 1 | **0 唯一**，范围 $-128 \sim +127$ |
| 移码 | 补码符号位**取反** | 同左 | 常用于表示**阶码**，便于比较大小 |

**核心性质**：补码把减法变成加法（$a - b = a + [-b]_补$），简化运算器设计——这是考题最爱问的"为什么用补码"。

### 例题演算

> 【例】若机器字长 8 位，$-1$ 的补码是（ ）。
> A. 10000001  B. 11111110  C. 11111111  D. 00000001

**答 C**。原码 10000001 → 反码 11111110 → 补码 11111111。

### 易错警示

- 补码表示范围比原码多一个负数（-128），因为 0 只占一个编码。
- 移码 = 补码符号位取反，不是"补码取反"。

## 1.3 浮点数的表示

### 精讲

浮点数 $N = M \times r^E$：$M$ 是尾数（决定**精度**），$E$ 是阶码（决定**范围**），$r$ 是基数。

- **规格化**：尾数最高有效位必须是有效数字。正数规格化形式 $0.1xx\ldots$；负数补码规格化形式 $1.0xx\ldots$
- **对阶**：小阶向大阶看齐（阶小的尾数右移）。
- 运算顺序：对阶 → 尾数运算 → **规格化** → 舍入 → 判溢出。
- **溢出判断**看**阶码**是否溢出，不是尾数。

> 【例】两浮点数，前者阶码长尾数短，后者阶码短尾数长，则前者（ ）。
> A. 范围大精度高  B. 范围大精度低  C. 范围小精度高  D. 相同

**答 B**。一句话记住：**阶码管范围，尾数管精度**。

### 易错警示

- "精度"看尾数位数，"范围"看阶码位数，考试经常把两者对调设错项。
- IEEE 754：float 32 位（1 符号 + 8 阶码 + 23 尾数），double 64 位。

## 1.4 校验码

### 精讲

**奇偶校验**：加 1 位使整个码字中 1 的个数为奇/偶数。只能发现**奇数个**位错，不能纠错。

**海明码**：数据 $n$ 位、校验 $k$ 位，满足 $2^k \ge n + k + 1$。校验位放在 $2^i$ 位置（1、2、4、8…），可**纠正一位错**。

> 【例】对 4 位数据编码需要（ ）位校验位？
> $2^3 = 8 \ge 4+3+1 = 8$ 成立 → **3 位**。

**CRC 循环冗余校验**：模 2 除法（异或运算）。发送方：信息码左移 $r$ 位（$r$ = 生成多项式最高次幂）后除以生成多项式，余数作校验位拼接。接收方：整个码字除以生成多项式，**余数为 0 则无错**。

> 【例】信息码 10110，生成多项式 $G(x)=x^3+x^2+1$（即 1101），求 CRC 码字。
> 左移 3 位：10110000 ÷ 1101（模 2 除）→ 余数 001 → 码字 **10110001**。

### 易错警示

- 海明码公式是 $2^k \ge n+k+1$，别记成 $2^k \ge n+k$。
- CRC 只能检错不能纠错（考试常与海明码对比）。

## 1.5 Cache 与存储体系

### 精讲

存储层次：寄存器 > Cache > 主存 > 外存，**越往上越快越贵越小**。依据是**局部性原理**（时间局部性 + 空间局部性）。

- **命中率 $h$** = 访问 Cache 命中次数 / 总访问次数。
- **平均访存时间** $t = h \times t_{cache} + (1-h) \times t_{memory}$（有的题加并行访问系数，按题干公式）。
- 地址映射：**直接映射**（主存块只能进唯一 Cache 行，硬件简单、冲突率高）、**全相联**（任意放，灵活但成本高）、**组相联**（折中，最常用）。
- Cache 与主存的地址映射由**硬件自动**完成，程序员不可见。

### 例题演算

> 【例】Cache 速度为主存的 5 倍，命中率为 90%，则平均访问时间为（ ）。
> 设主存 500ns，Cache 100ns：$t = 0.9 \times 100 + 0.1 \times 500 = 140$ ns。

### 易错警示

- "Cache 对程序员透明"——透明 = 看不见 = 不可编程管理。
- 平均访存时间公式要看题干给的是"同时访问"还是"先 Cache 后主存"，后者未命中时间要加 $t_{cache}$。

## 1.6 磁盘与可靠性计算

### 精讲

**磁盘参数**：
- 磁道容量 = 位密度 × 周长（通常按"每道字节数"给出）。
- 数据传输率 $C$ = 每道容量 × 转速。
- 平均旋转等待时间 = 转一圈时间的一半 = $\frac{60}{2 \times 转速(rpm)}$。
- 平均存取时间 = 平均寻道时间 + 平均旋转等待 + 传输时间。

**可靠性**（串联、并联是必考计算）：

| 结构 | 可靠度公式 |
|---|---|
| 串联 | $R = R_1 \times R_2 \times \cdots \times R_n$（一个坏全坏） |
| 并联 | $R = 1 - (1-R_1)(1-R_2)\cdots$（全坏才坏） |
| 混联 | 先局部后整体分解 |

> 【例】系统由 2 个可靠度 0.9 的部件串联，再与 1 个 0.9 的部件并联，求系统可靠度。
> 串联部分：$0.9 \times 0.9 = 0.81$；与第三个并联：$1 - (1-0.81)(1-0.9) = 1 - 0.19 \times 0.1 = 0.981$。

**MTBF/MTTR**：可靠性 $R = \frac{MTTF}{MTTF + MTTR}$，可维护性 $M = \frac{MTTR}{MTTF + MTTR}$，可用性 $A = \frac{MTBF}{MTBF + MTBR}$。

### 易错警示

- 并联用"1 减全坏"，直接加可靠度是常见错误。
- 混联题先画等效图再分步算。

| 可维护性 | MTTR / (MTTF+MTTR) |
