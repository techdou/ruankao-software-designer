## 本章考情

每年 4~6 分。**OSI 层次与设备归属、子网划分计算、常用协议端口**是三大高频。近年 IPv6、DHCP 过程、无痕浏览这类应用题增多，难度不高。

## 11.1 OSI 与 TCP/IP

### 精讲

**OSI 七层**（下到上）：物理、数据链路、网络、传输、会话、表示、应用。
**TCP/IP 四层**：网络接口、网际（IP）、传输（TCP/UDP）、应用。

**设备与协议归属**（必考）：

| 层 | 设备 | 代表协议/PDU |
|---|---|---|
| 物理层 | 中继器、集线器 Hub | 比特 |
| 数据链路层 | **网桥、交换机** | 帧；VLAN tag(802.1Q)、PPP |
| 网络层 | **路由器**、三层交换机 | IP、ICMP、ARP、IGMP、路由协议 |
| 传输层 | —（防火墙常在此） | TCP、UDP |
| 应用层 | 网关 | HTTP、DNS、SMTP… |

- **ARP**：IP → MAC；**ICMP**：差错报告（ping 用它）；**IGMP**：组播成员管理（**不能远程登录**）。
- 数据链路层在物理线路上提供**可靠**传输服务的是有应答的链路协议（如 HDLC），普通以太网提供的是不可靠服务。

### 易错警示

- 交换机是二层、路由器是三层——"用交换机连接不同网段"是错的，要路由器/三层交换机。
- TCP/IP 没有会话层和表示层。

## 11.2 IP 地址与子网（必考计算）

### 精讲

| 类 | 首位 | 默认掩码 | 范围 | 私有地址 |
|---|---|---|---|---|
| A | 0 | /8 | 1~126 | 10.0.0.0/8 |
| B | 10 | /16 | 128~191 | 172.16~31 |
| C | 110 | /24 | 192~223 | 192.168.0.0/16 |
| D | 1110 | 组播 | 224~239 | — |

- 127.x.x.x 回环；主机位全 0 = 网络地址，全 1 = 广播，**可用主机数 = $2^h - 2$**。
- **子网划分**：借用主机位 k 位 → $2^k$ 个子网。
- **路由聚合（CIDR）**：取多个网络地址的公共前缀。
- 169.254.x.x：DHCP 失败后的**自动专用地址（APIPA）**。

> 【例】把 192.168.1.0/26、192.168.1.64/26、192.168.1.128/26、192.168.1.192/26 聚合 → 公共前缀 /24：**192.168.1.0/24**。

> 【例】202.113.100.0/24 划分出至少 20 个子网、每个子网至少 5 台主机：k=5 → 32 个子网，主机位 3 位只剩 6 台 ✓——取平衡点 /27。

### 易错警示

- 可用主机数别忘减 2；聚合找公共前缀，别简单加掩码长度。

## 11.3 TCP 与 UDP

### 精讲

| | TCP | UDP |
|---|---|---|
| 连接 | 面向连接（三次握手/四次挥手） | 无连接 |
| 可靠性 | 可靠（确认重传、滑动窗口流量控制、拥塞控制） | 尽力而为 |
| 场景 | HTTP、FTP、SMTP、Telnet | DNS、DHCP、视频直播 |

- 三次握手：SYN → SYN+ACK → ACK（**确认双方收发能力**）。
- 窗口机制：接收方通告窗口控制发送速率（流量控制）。

### 易错警示

- DNS 主要用 UDP（区域传送用 TCP）；DHCP 用 UDP。

## 11.4 应用层协议与端口（必背表）

| 协议 | 端口 | 传输 | 备注 |
|---|---|---|---|
| FTP | **20(数据)/21(控制)** | TCP | |
| SSH | **22** | TCP | 安全远程登录 |
| Telnet | **23** | TCP | 明文不安全 |
| SMTP | **25** | TCP | **发**邮件 |
| DNS | **53** | UDP/TCP | 域名→IP |
| HTTP | **80** | TCP | |
| POP3 | **110** | TCP | 收邮件 |
| SNMP | 161 | UDP | 网管 |
| HTTPS | **443** | TCP | HTTP+SSL/TLS |

**DHCP 四步**：Discover（广播）→ Offer → Request → ACK；租约一半时续租。**DNS 解析**：主机→本地域名服务器**递归**；本地→根/顶级/权限服务器**迭代**。域名结构：`主机名.三级.二级.顶级.根`，**cn 是国家顶级域**。

**电子邮件**：发件用 **SMTP**，收件用 POP3/IMAP4（MIME 是格式扩展）；POP3 连接端口 110。

### 易错警示

- "客户端发送邮件" = SMTP；"从服务器收取" = POP3/IMAP。
- HTTPS=443、SSH=22、Telnet=23 三兄弟别混。

## 11.5 其他高频小题

- **IPv6**：128 位、冒号十六进制、可零压缩（`::` 只能出现一次）、取消广播（用组播/任播）。
- **无痕浏览**：不保存历史/Cookie/表单记录，但**下载的文件与收藏夹**仍保留。
- **支付网关**：Internet 与银行专用网之间交换支付数据的节点。
- **web 无痕**、**浏览器缓存清除**：`ipconfig/flushdns` 清 DNS 缓存（这是系统命令不是浏览器）。
- 无线局域网标准：802.11 系列（a/b/g/n/ac）；以太网 802.3。
