## 本章考情

每年约 4~6 分。**流水线三连算（执行时间/吞吐率/加速比）是每年必考的计算题**，中断、CISC/RISC 对比是稳定送分题。DMA 与中断的区别几乎隔年考一次。

## 2.1 CISC 与 RISC

### 精讲

| 维度 | CISC | RISC |
|---|---|---|
| 指令数量 | 多（200+），变长 | 少（<100），**等长** |
| 指令使用频率 | 差异大 | 选取**使用频率高**的指令 |
| 寻址方式 | 丰富 | 少 |
| 通用寄存器 | 少 | **大量** |
| 控制器实现 | **微程序控制**为主 | **组合逻辑（硬布线）** |
| 流水线 | 较难实现 | **普遍采用**、优化编译配合 |
| 访存 | 多种指令都可访存 | **只有 Load/Store 指令访存** |

### 易错警示

- 反向选项："RISC 不采用流水线""RISC 指令功能强""RISC 寄存器少"全错——RISC 恰恰相反。
- 微程序控制器 vs 组合逻辑控制器：CISC 指令复杂用微程序（易扩展），RISC 指令规整用硬布线（速度快）。

## 2.2 流水线（每年必考）

### 精讲

把指令执行分成 $k$ 个子过程（取指、分析、执行…），每个子过程耗时 $\Delta t$（时钟周期）。

| 指标 | 公式 |
|---|---|
| 执行 $n$ 条指令总时间 | $T = (k + n - 1)\Delta t$ |
| 吞吐率 TP | $\dfrac{n}{(k+n-1)\Delta t}$，极限 $\dfrac{1}{\Delta t}$ |
| 加速比 S | $\dfrac{n \cdot k \Delta t}{(k+n-1)\Delta t} = \dfrac{nk}{k+n-1}$，极限 $k$ |

**瓶颈**：各段耗时不一时，$\Delta t$ 取最长的子过程时间。**冲突**类型：资源冲突、数据相关（后条指令用到前条结果）、控制相关（转移指令）。

> 【例】流水线分取指、分析、执行 3 段，每段 1ns，执行 100 条指令需（ ）ns？
> $T = (3 + 100 - 1) \times 1 = 102$ ns。

### 易错警示

- $k+n-1$ 不是 $k \times n$：第一条指令走完全程后每 $\Delta t$ 出一条。
- 加速比极限是 $k$（段数），吞吐率极限是 $1/\Delta t$。

## 2.3 中断与 DMA

### 精讲

**中断**：CPU 暂停当前程序转去处理突发事件，处理完返回。异常（内部，如除零、溢出）vs 中断（外部请求，如 I/O 完成）。

- **中断向量** = 中断服务程序的**入口地址**，存放在中断向量表中。
- 中断响应时间：发出中断请求到**开始执行中断服务程序**的时间。
- 多级中断用**堆栈**保存现场（嵌套返回）。
- 中断传送仍需 CPU 执行服务程序干预。

**DMA（直接存储器存取）**：数据在主存与外设之间直接传送，**不需要 CPU 执行程序搬运**，只在传送前后干预。传送时采用**周期挪用（窃取）**：每传一个数据占用一个**存储周期**。

| 对比 | 程序中断 | DMA |
|---|---|---|
| CPU 干预 | 传送全程执行程序 | 仅初始化和结束 |
| 数据通路 | 经 CPU 寄存器 | 主存 ↔ 外设直通 |
| 速度 | 慢（低速率设备） | 快（块设备） |
| 保护现场 | 需要 | 不需要 |

> 【例】"DMA 传送结束"是中断，"除数为 0"是异常——DMA 结束是外设向 CPU 发的中断请求，除零是 CPU 内部异常。

### 易错警示

- "中断方式不需要 CPU 干预"是错误说法，DMA 才基本不需要。
- DMA 每传一个数据占一个**存储周期**（不是指令周期/总线周期）。

## 2.4 总线与 RAID

### 精讲

**总线分类**：数据总线（双向传数据）、地址总线（单向，位数决定寻址空间）、控制总线。按位置分：内部总线（芯片内）、系统总线（板卡间，如 PCI **并行内总线**）、外部总线（设备间，如 USB、SCSI **并行外总线**）。

**RAID**（独立磁盘冗余阵列）：

| 级别 | 特点 |
|---|---|
| RAID 0 | 条带化，无冗余，**不提高可靠性**，性能最好 |
| RAID 1 | 镜像，利用率 50%，可靠性最高 |
| RAID 5 | 分布式奇偶校验，**至少 3 块盘**，坏 1 块可恢复 |
| RAID 6 | 双重校验，可坏 2 块 |
| RAID 10 | 先镜像后条带（1+0） |

### 易错警示

- RAID 0 可靠性**不升反降**（任一盘坏数据全丢）。
- PCI 是并行**内**总线，SCSI 是并行**外**总线——内外之分年年考。

## 2.5 校验、寻址与嵌入式

### 精讲

**寻址方式速度排序**：立即寻址（操作数在指令中，取指即得）> 寄存器寻址（在寄存器中）？——注意：**寄存器寻址最快，立即寻址次之，直接寻址最慢**（直接寻址还要再访存一次）。

**Flynn 分类**：SISD（单指令单数据流，传统单处理机）、SIMD（阵列处理机、GPU）、MISD（罕见）、MIMD（多处理机）。

**嵌入式系统**：以应用为中心、软硬件可裁剪、**实时性**要求高；RTOS 的调度强调**截止时间**（硬实时/软实时）。嵌入式处理器特点：低功耗、集成度高。

### 易错警示

- 寻址速度题：寄存器 > 立即 > 直接。立即寻址虽不用访存取操作数，但操作数随指令走，等长指令下不如寄存器快——按教材结论记。
- 冯·诺依曼机核心：**存储程序**、指令和数据同等地存于主存、按地址访问、顺序执行。
