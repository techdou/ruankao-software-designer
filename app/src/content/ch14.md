## 本章考情

每年 4~6 分：数学 2~3 题（逻辑等价、排列组合、线性规划）+ 专业英语固定 5 题（1 篇短文 5 空）。英语题**高频术语复现率极高**，考前突击性价比全场最高。

## 14.1 命题逻辑

### 精讲

联结词：¬ 非、∧ 与、∨ 或、→ 蕴含、↔ 等价。**蕴含真值表**：只有"真→假"才为假。

**常用等价式**：

- $P \to Q \Leftrightarrow \neg P \lor Q$
- $\neg(P \lor Q) \Leftrightarrow \neg P \land \neg Q$（德摩根）
- $P \to Q \Leftrightarrow \neg Q \to \neg P$（逆否命题）
- $P \to (Q \to R) \Leftrightarrow (P \land Q) \to R$

**推理规则**：P→Q, P ⊢ Q（假言推理/分离规则）；P→Q, ¬Q ⊢ ¬P（拒取式）。

> 【例】"并非'甲且乙都合格'" = ¬(P∧Q) = **¬P ∨ ¬Q**。

### 易错警示

- $P \to Q$ 与 $Q \to P$ 不是等价式（别把"如果"的方向搞反）。

## 14.2 组合计数

### 精讲

- 加法原理（分类）、乘法原理（分步）。
- 排列 $A_n^m = \frac{n!}{(n-m)!}$（有序）；组合 $C_n^m = \frac{n!}{m!(n-m)!}$（无序）。
- **鸽巢原理**：n+1 个鸽子进 n 个巢，必有一个巢 ≥2。
- 常见模型：n 人两两握手 $C_n^2$；网状拓扑连线数同。

> 【例】367 个人中必有 2 人生日相同（鸽巢：366 天）。

## 14.3 线性规划与其他数学

- **图解法**：约束围成**可行域**（凸多边形），目标函数在**顶点**取最优。
- 排序不等式、抽屉原理是"至少/保证"类题的核心。
- 概率基础：互斥事件加法、独立事件乘法。

## 14.4 专业英语 5 题（固定送分）

### 精讲

**出题模式**：一篇 300 词左右短文（软件工程/面向对象/网络/数据库主题），挖 5 个空，四选一。**90% 的空是术语复现**，靠词性搭配 + 上下文即可锁定。

**解题三步**：

1. 空前后是冠词 the/a + ______ + of → 填**名词**。
2. 术语搭配：requirements **specification**、design **patterns**、**inheritance** hierarchy。
3. 四个选项中三个同词性时，用"哪一个是本文主题的高频词"判断。

**高频术语表**（历年反复出现）：

| 术语 | 中文 | 术语 | 中文 |
|---|---|---|---|
| requirement | 需求 | maintenance | 维护 |
| specification | 规格说明 | modification | 修改 |
| prototype | 原型 | regression | 回归 |
| design pattern | 设计模式 | encapsulation | 封装 |
| inheritance | 继承 | polymorphism | 多态 |
| object-oriented | 面向对象 | class hierarchy | 类层次 |
| reusable | 可复用的 | granularity | 粒度 |
| component | 构件 | interface | 接口 |
| database | 数据库 | normalization | 规范化 |
| query | 查询 | transaction | 事务 |
| network protocol | 网络协议 | firewall | 防火墙 |
| encryption | 加密 | authentication | 认证 |
| distributed | 分布式的 | concurrent | 并发的 |
| embedded system | 嵌入式系统 | real-time | 实时 |

**历年真题句式积累**：

- GoF《设计模式》序言（2021 上考过）：designing **reusable** object-oriented software is even harder; you must find **pertinent** objects…
- SOA/Web services（2022 下考过）：SOA is an architectural **style**; Web services are a **technology**; services are exposed through **interfaces**.

### 易错警示

- 英语题选项常见"形近词陷阱"（affect/effect），先判词性再判词义。
- 一篇短文 5 个空通常按行文顺序排列，答案分布均匀，别 5 个空全选同一位置。
