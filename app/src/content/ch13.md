## 本章考情

每年 2~3 分，**纯记忆、零计算、必须全对**的送分章。著作权归属与保护期是绝对主角，专利/商标轮流出题。

## 13.1 软件著作权（重点）

### 精讲

**保护对象**：程序 + 文档（**目标程序、源程序、文档都保护**；思想、算法、操作方法不受保护）。**自动取得**，无需登记（登记只是证据）。

**归属规则**（考烂的五条）：

| 情形 | 归属 |
|---|---|
| 个人独立开发 | 开发者本人 |
| **职务作品**（利用单位物质技术条件、本职工作） | **单位**享有（署名权归作者） |
| **委托开发**，有合同 | 按合同约定 |
| **委托开发，无合同/未约定** | **受托人**（开发方）享有 |
| **合作开发**，无约定 | 共同享有，可分割则各自转让所得部分 |

**保护期速记表**：

| 权利 | 期限 |
|---|---|
| 署名权、修改权、保护作品完整权 | **不受限制（永久）** |
| 发表权、财产权（自然人） | 作者**终生 + 死后 50 年**（至 12.31） |
| 发表权、财产权（单位作品） | **首次发表后 50 年** |
| 合作开发 | 至最后死亡作者死后 50 年 |

**善意使用**：不知情购买盗版软件使用 → 不承担赔偿责任，但应停止使用、销毁；若销毁损失重大，可**支付合理费用后继续使用**。知情后继续使用则侵权。

> 【例】甲乙先后就相同发明申请专利，甲早一日 → **甲**获专利申请权（先申请原则）。

### 易错警示

- 委托开发默认归**受托方**，反向选项"归委托方"是陷阱。
- "翻译权"在软件条例中指**自然语言之间**的转换，不是程序语言。

## 13.2 专利、商标、商业秘密

### 精讲

**专利**（需申请、审查、授权）：

| 类型 | 保护期 |
|---|---|
| 发明 | **20 年** |
| 实用新型 | **10 年** |
| 外观设计 | **15 年**（2021 年起） |

先申请原则：同日申请协商。软件本身不授专利，但**含技术方案的发明**可以。

**商标**：注册在先原则（但**使用在先**的他人已用商标可获准注册的对抗情形要会）；有效期 **10 年**，**可以无限次续展**（每次 10 年）。注册商标需要**申请**，未注册不享有商标专用权。

**商业秘密**：秘密性 + 价值性 + 保密措施；**只要不泄密就无限期**；被反向工程不侵权。

**保护期可延长的**：注册商标（续展）。

> 【例】公司注册商标 S + 保密约束 + 软件著作权 → 不享有的是**专利权**（没申请）。

### 易错警示

- 著作权自动取得 vs 专利/商标须申请——"自动享有专利权"必错。
- 商业秘密无期限 vs 专利有期限，是"公开换保护"。

## 13.3 标准化

### 精讲

| 层级 | 代号 | 例 |
|---|---|---|
| 国际标准 | ISO/IEC | |
| 国家标准 | **GB（强制）、GB/T（推荐）** | GB/T 8567 |
| 国防 | GJB | |
| 行业标准 | **行业代号 + /T** | SJ/T、JR/T |
| 地方标准 | DB | |
| 企业标准 | Q/ | |

强制性标准必须执行；推荐性（/T）自愿采用，一经引用于合同即具约束力。

标准化法层级口诀：**国、行、地、企**（国际另算）。

## 考前速记

| 考点 | 一句话 |
|---|---|
| 著作权取得 | 自动，无需登记 |
| 委托开发无约定 | 归受托人 |
| 职务作品 | 归单位 |
| 署名/修改/完整权 | 永久保护 |
| 财产权 | 终生+50 / 发表后 50 年 |
| 善意使用 | 停止使用；付费可继续 |
| 专利 | 发明 20 / 实用新型 10 / 外观 15 |
| 商标 | 10 年可无限续展 |
| 保护期可延长 | 商标（续展） |
| GB / GB/T | 强制 / 推荐 |
