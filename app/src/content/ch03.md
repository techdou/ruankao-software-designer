## 本章考情

每年约 4~6 分。编译阶段划分、传值/传引用演算、有限自动机识别是三大高频考点；近年 Python 基础题每年 2~3 道（列表/元组/切片/异常），属于白送分，必须全拿。

## 3.1 编译与解释

### 精讲

| | 编译方式 | 解释方式 |
|---|---|---|
| 过程 | **先翻译**成目标程序，再执行 | **边翻译边执行**，不生成目标程序 |
| 运行效率 | 高 | 低 |
| 可移植性 | 差（绑定平台） | 好 |
| 典型语言 | C/C++/Go | Python/JS/Shell（Java 混合：编译成字节码 + JVM 解释/JIT） |

**编译的六个阶段**（考"某工作属于哪个阶段"）：

1. **词法分析**：字符流 → 单词（记号）序列。识别标识符、关键字、常数。
2. **语法分析**：单词序列 → 语法树，检查结构合法性。
3. **语义分析**：**类型检查**、运算合法性、语义一致。
4. 中间代码生成：四元式、三元式、逆波兰式。
5. 代码优化。
6. **目标代码生成**。

贯穿始终的辅助结构：**符号表**（记录变量、函数的类型/作用域等信息）和**错误处理**。

> 【例】C/C++ 编译过程中类型检查在（ ）阶段。→ **语义分析**。

### 易错警示

- "生成中间代码""优化"属于编译阶段，解释器没有独立的优化阶段。
- Java：先编译成字节码（.class），再由 JVM 解释/JIT 执行——考"即时编译（JIT）+ 对象在堆分配 + 自动垃圾回收"。

## 3.2 文法与正规式

### 精讲

乔姆斯基文法分类（按产生式形式限制从宽到严）：

| 类型 | 名称 | 对应自动机 |
|---|---|---|
| 0 型 | 短语结构文法 | 图灵机 |
| 1 型 | 上下文有关文法 CSG | 线性有界自动机 |
| **2 型** | **上下文无关文法 CFG** | **下推自动机**（程序语言语法多用 CFG） |
| 3 型 | 正规文法 | **有限自动机**（词法） |

**有限自动机**：DFA（每个状态对每个输入只有唯一转移）与 NFA（可有多个转移/ε 转移）。读状态图判断"能识别什么串"：从初态出发穷举走到终态的路径规律——常考"以 101 开头/结尾""不含连续 00"之类描述。

> 【例】正规式 $(a|b)^*$ 表示：由 a、b 组成的任意串。（有限次重复用 $^*$，至少一次用 $+$，可选用 $\epsilon$。）

### 易错警示

- 语法分析用 CFG（2 型），**词法分析**用正规式/有限自动机（3 型）——层次别混。
- 自动机题若原图缺失，用"最长可接受样本串代回验证"法排除选项。

## 3.3 后缀表达式与语法树

### 精讲

后缀式（逆波兰式）：操作数在前、运算符在后，无括号。手算方法：**先画括号，把每个二元运算的运算符挪到对应右括号处**，再按序抄写。

> 【例】$a*(b+c/d)-e$
> 第一步加括号：$(a*(b+(c/d)))-e$
> 运算符后挪：$a\ (b\ c\ d\ / +) * e -$
> 得：**abcd/+*e-**

语法树：运算符做内部结点、操作数做叶子；**后序遍历**语法树即后缀式，中序（加括号）是中缀。

### 易错警示

- 后缀式转换中最容易错的是运算优先级嵌套，务必先补全括号再挪运算符。

## 3.4 参数传递（每年必考）

### 精讲

- **传值调用**：把实参的**值复制**给形参，函数内修改形参**不影响**实参。
- **引用调用**：把实参的**地址**传给形参，函数内修改形参**直接改变**实参。

> 【例】
> ```c
> void hoo(int x, int y) { y = y + 10; x = y - x; }  // x 传值, y 传引用
> int a = 2;
> hoo(a, a);
> print(a);   // a = ?
> ```
> 进函数：x = 2（复制），y 是 a 的引用。y = 2+10 = 12 → **a 变 12**；x = 12 − 2 = 10（只改形参 x，不影响 a）。输出 **12**。

解题套路：**画两个格子**（值参数一个格子，引用参数指向实参），逐行执行，改引用格子时同步改实参。

### 易错警示

- C 语言**只有传值**（传地址本质是传指针值）；C++/Java（对象参数）才有真正的引用语义。
- 两个参数一个是传值一个是引用时，先算传引用的那个对实参的更新，再按代码顺序执行。

## 3.5 作用域、栈帧与闭包

### 精讲

- **静态作用域**（词法作用域）：由**程序文本定义位置**决定（C/Java/Python）。
- **动态作用域**：由**调用链**决定（Lisp 类）。
- **栈帧（活动记录）**：函数调用时在栈顶开辟，含**形参、局部变量、返回地址、寄存器现场**；**全局变量在静态区，不在栈帧中**。递归/嵌套调用靠栈帧保证正确返回。
- **动态绑定（晚绑定）**：运行时才确定调用的具体实现——多态的基础。

### 易错警示

- "栈帧中不包括全局变量"是送分反选题。
- 静态绑定 = 编译期确定（重载、private/static 方法）；动态绑定 = 运行期确定（覆盖/重写）。

## 3.6 Python 高频小题

### 精讲

| 考点 | 结论 |
|---|---|
| 类型 | 解释型、动态类型、跨平台、开源 |
| 列表 `list` | **可变、有序、可重复**：`X*2` 是元素重复拼接 `[1,2,1,2]` |
| 元组 `tuple` | **不可变、有序、可重复** |
| 集合 `set` | 无序、**不重复** |
| 字符串 | 不可变；切片 `[start:stop:step]` **不含 stop** |
| 切片示例 | `list(range(11))[10:0:-2]` → `[10,8,6,4,2]`（从 10 倒着取到 1） |
| 输入 | `input()` 返回**字符串**，要 `int()` 转换 |
| 异常 | `try...except...finally`，**没有 catch**；`raise` 手动抛出 |
| 安装模块 | `pip install numpy` |
| 深度学习 | TensorFlow / PyTorch / Keras；**Matplotlib 只画图** |

### 易错警示

- 负步长切片 `[::-1]` 反转；`[10:0:-2]` 不含下标 0——stop 永远取不到。
- 元组可重复、集合不可重复，两者都"无序"是错的（元组有序）。

## 考前速记

| 考点 | 一句话 |
|---|---|
| 编译 vs 解释 | 先翻后执效率高 / 边翻边执可移植好 |

| 符号表 | 记录符号信息，辅助语义检查与代码生成 |

| 递归下降 | 自上而下分析；LR/算符优先 = 自下而上 |
| 传值 / 传引用 | 复制不影响实参 / 改地址直接改实参 |
| 栈帧 | 形参+局部+返回地址；全局变量在静态区 |
| Python | list 可变有序、tuple 不可变有序、set 无序不重复 |
